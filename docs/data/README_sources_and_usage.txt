IMPORTANT DATA NOTE
The year-wise table in source A sums to 315, whereas the later source B reports 317 for the same five-year period. The chart deliberately uses the annexure's year-wise values (62, 88, 65, 54, 46) and flags the discrepancy. Verify/resolve this before the final report. Do not silently mix the totals.

AVROD project-report guidance
These external-data charts support the problem and policy context. Add a separate prototype-validation chart using your actual test logs (e.g. raw ADC readings over time, threshold-crossing response, RFID acceptance tests, and simulated post-entry alarm outcomes). Do not create or imply experimental results without measurements. The project's gas ADC numbers are raw sensor counts, not calibrated gas concentrations.
